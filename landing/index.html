FlagFlow – Feature Flag Service auto-hospedado

Activá y desactivá funcionalidades en tus apps sin redeploy. Cloná el repo, ejecutá docker-compose up -d y tenés tu API en localhost:8080.

Ver en GitHub Cómo instalar

¿Qué son los feature flags?

Son interruptores que controlan si una funcionalidad está visible para tus usuarios. Sirven para despliegues seguros, rollouts graduales (10% → 50% → 100%), pruebas A/B y apagar una feature en producción al instante sin volver a desplegar.

Sin dependencia de la nube

No usás LaunchDarkly ni servicios de pago. Todo corre en tu máquina con Docker.

API en Go

Concurrencia real: cache con mutex, goroutines y cientos de consultas simultáneas.

SDK para React

Integrá flags en el frontend apuntando a http://localhost:8080.

Instalación en 3 pasos

Requisito Solo necesitás Docker y Docker Compose.

  1. Clonar el repositorio
    git clone https://github.com/ovejero92/flagflow.git
    cd flagflow
  2. Levantar el stack
    docker-compose up -d
    Postgres + API Go. Migraciones automáticas al iniciar.
  3. Usar la API
    Abrí http://localhost:8080/api/v1/health y creá apps/flags con curl o el SDK.

Atajo: ./start.sh (Mac/Linux) o start.bat (Windows) levanta Docker y abre el navegador.

Probar con curl

Creá una aplicación, un flag y consultalo en el endpoint público:

# Health
curl http://localhost:8080/api/v1/health

# Crear app (guardá el "id" de la respuesta)
curl -X POST http://localhost:8080/api/v1/apps \
  -H "Content-Type: application/json" \
  -d '{"name":"mi-app","description":"demo"}'

# Crear flag (reemplazá APP_ID)
curl -X POST http://localhost:8080/api/v1/apps/APP_ID/flags \
  -H "Content-Type: application/json" \
  -d '{"name":"dark-mode","enabled":true,"rollout_percentage":50}'

# Consultar flag (público, con cache)
curl http://localhost:8080/api/v1/public/flag/APP_ID/dark-mode \
  -H "X-User-Id: user-123"

Integración con React

Copiá pkg/sdk/js/feature-flags-sdk.ts a tu proyecto:

import { FeatureFlagClient } from "./feature-flags-sdk";

// Por defecto usa http://localhost:8080
const client = new FeatureFlagClient("TU-APP-UUID");

const darkMode = await client.isEnabled("dark-mode", "user-123");
Cache local 5s en el SDK
Rollout % consistente por usuario
CORS habilitado para frontends locales

Detener el servicio

docker-compose down

Para borrar también los datos de Postgres: docker-compose down -v
